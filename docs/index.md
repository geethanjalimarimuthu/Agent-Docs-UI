# Polaris AI Agents UI

Welcome to the **Polaris AI Agents UI** documentation. This guide will help you create, manage, and operate AI agents in a collaborative multi-tenant environment.

![Polaris AI Agents UI banner]({{ '/assets/images/home-hero.svg' | relative_url }})

## What is Polaris AI Agents UI?

Polaris AI is an enterprise platform for:

- **Creating AI agents** with intuitive interfaces
- **Versioning and managing** agent configurations
- **Orchestrating workflows** with a visual node editor
- **Integrating models** from leading providers
- **Connecting external agents** and tools
- **Managing MCP servers** for extensibility

## Key Features

| Feature | Description |
|---------|-------------|
| **Agent Builder** | Visual interface to design and compose AI agents |
| **Version Control** | Save, version, and revert agent configurations |
| **Model Registry** | Register and manage LLM providers (OpenAI, Claude, Bedrock, etc.) |
| **External Agents** | Connect and manage agents from external systems |
| **MCP Tools** | Register and use Model Context Protocol servers |
| **Multi-Tenant** | Organize agents and settings per tenant/workspace |
| **Role-Based Access** | Admin and user-level permission controls |
